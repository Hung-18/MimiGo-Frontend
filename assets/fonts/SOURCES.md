# Bundled typography

The local BR1 brand board and BA/UI PDF page 7 name Baloo 2 (or Fredoka) for headings/buttons and Nunito for Android body copy. This client uses Baloo 2 and Nunito, bundled offline. No font network requests, tracking SDK or Apple SF Pro redistribution.
