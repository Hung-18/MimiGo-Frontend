# Original storybook scenery

Generated with the built-in imagegen tool on 2026-11-05 for this Flutter delivery.
No source-board crops or external artwork were used as inputs. Both images are
1536×1024 PNGs, bundled offline; approximately 6 MiB decoded RGBA per atlas.
`garden.png` is used with cover cropping and decorative semantics excluded.
`domains.png` is a 3×2 atlas: Math, Language, English, Life skills, Logic, Explore.
These pictures are decorative domain navigation, never authored lesson content,
answers, progress or promises that a domain has available lessons.

Existing `assets/mascot/mimi_poses.png` remains the shared seven-pose companion;
the scene's dimensional light and palette were selected to harmonize with it.
No perpetual scenery animation or additional image dependency was added.
